## ADDED Requirements

### Requirement: 当前经营汇总
系统 SHALL 为管理员计算并展示当前时刻的有效 API Key 收入、有效私下客户订阅收入、总收入、直接成本、毛利、运营费用、净利润以及对应利润率。

#### Scenario: 当前汇总包含两类收入
- **WHEN** 管理员打开经营看板且同时存在有效计费 API Key 与有效私下客户订阅
- **THEN** 系统分别展示两类收入并将其合并为总收入

#### Scenario: 收入为零时利润率安全
- **WHEN** 当前总收入为零
- **THEN** 系统将毛利率和净利率返回为0且不产生除零错误

### Requirement: 有效收入来源口径
系统 MUST 只计算未删除、状态有效、具有明确未过期时间且能解析经营价格的 API Key，并计算未删除且到期日不早于北京时间当前日期的私下客户订阅。

#### Scenario: 无过期时间的 Key 不计入严格收入
- **WHEN** 一个状态为 active 的 API Key 没有 `expires_at`
- **THEN** 系统不把该 Key 计入收入并在异常数量中报告

#### Scenario: 已过期客户订阅不计收入
- **WHEN** 私下客户订阅的到期日早于北京时间当前日期
- **THEN** 系统不把该订阅计入当前收入

### Requirement: 历史月份展示
系统 SHALL 展示已保存的历史月份和当前月份，并 MUST NOT 生成或展示未来月份的收入或利润预测。

#### Scenario: 历史图表不含未来月份
- **WHEN** 管理员查看月度经营趋势
- **THEN** 图表最多显示当前月份且不存在当前月份之后的数据点

#### Scenario: 选择历史月份
- **WHEN** 管理员选择一个已锁账月份
- **THEN** 系统从该月快照返回收入、成本、利润和有效客户明细，而不是用当前数据重算

### Requirement: 月份交互与解释
系统 SHALL 在月度图表 Tooltip 中展示该月收入、直接成本、运营费用、毛利、净利润和客户数量，并允许管理员打开完整明细。

#### Scenario: 悬停月份
- **WHEN** 管理员将指针或键盘焦点移到一个月份数据点
- **THEN** 系统展示该月核心汇总和相对上月的客户增减

#### Scenario: 打开月份明细
- **WHEN** 管理员点击一个月份
- **THEN** 系统展示该月每个 API Key、客户订阅和成本项目的快照金额与计入原因

### Requirement: 经营指标公式
系统 MUST 使用“毛利 = 总收入 - 直接成本”和“净利润 = 毛利 - 运营费用”的公式，并以 CNY 作为报表本位币。

#### Scenario: 多币种成本参与利润计算
- **WHEN** 当月存在 USD 成本且配置了当月 USD/CNY 汇率
- **THEN** 系统先按锁定汇率折算为 CNY，再计算毛利和净利润

### Requirement: 管理员权限与敏感信息保护
系统 MUST 仅向管理员开放经营页面和 API，且 MUST NOT 返回原始 API Key、OAuth token、数据库凭据或其他账号秘密。

#### Scenario: 普通用户访问经营接口
- **WHEN** 非管理员请求任一经营管理 API
- **THEN** 系统拒绝请求且不返回经营数据
